# Fire Mok Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Flood-monitoring platform for Rio Grande do Sul: SAR water-extent detection + vulnerability layers + IBGE community panel, served by a FastAPI tile/JSON backend and a React+MapLibre frontend.

**Architecture:** Python pipeline (uv, Python 3.13) downloads SAR scenes (Sentinel-1 RTC via MS Planetary Computer — no auth; NISAR GCOV via ASF — Earthdata when ready), produces COG rasters (σ0 dB, water masks, flood diff) and GeoJSON layers (municipalities, risk scores). FastAPI serves PNG tiles via titiler (`expression` param drives the interactive σ0 threshold) plus JSON endpoints for municipalities/risk/action-plan. React+MapLibre renders layers, before/after swipe, time slider, municipality panel.

**Tech Stack:** Python 3.13 + uv · rasterio, rio-tiler, titiler.core, pystac-client, planetary-computer, geopandas, numpy, httpx, asf_search · FastAPI+uvicorn · Vite+React+TS+MapLibre GL.

**Spec:** `docs/superpowers/specs/2026-11-14-fire-mok-design.md`

## Global Constraints

- Python **3.13** via `uv` (never the system 3.14 — rasterio wheels).
- All data artifacts land in `data/` (gitignored); tests use `tests/fixtures/` (committed).
- SAR sensors stay in separate layers — never diff NISAR (L-band) against Sentinel-1 (C-band).
- No LLM/paid service on the demo path. Earthdata creds optional; absence must degrade gracefully, never crash.
- Risk output is a screening score, labeled as such — never an official civil-defense warning.
- Portuguese UI labels (municipal audience); code/comments in English.
- AOI default: bbox around Guaíba/Porto Alegre `(-51.6, -30.4, -50.7, -29.7)` (lon/lat, EPSG:4326); secondary Vale do Taquari `(-52.4, -29.5, -51.6, -29.0)`.

## Review Focus

Inputs the spec implies but no task test pins — each gets a test in the owning task:

1. STAC search returns 0 scenes for AOI/window → expect: empty list, pipeline logs and widens window; never raises.
2. Earthdata creds missing → expect: NISAR step logs "skipped: no Earthdata creds", exits 0.
3. Municipality with zero flood intersection → expect: risk band "baixo", non-empty generic checklist, no division by zero.
4. SAR scene only partially overlapping AOI → expect: masked nodata fill, not an error or distorted output.
5. IBGE API unreachable → expect: fall back to committed `tests/fixtures/` GeoJSON, log warning.
