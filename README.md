# fire-mok

## Problema

Os ultimos anos vem passando por mudanças climáticas intensas. Deixamos do processo de aquecimento global para uma nova era de ebulição global. Ondas de calor, altas temperaturas, incêndios na Amazônia, e grandes enchentes, como as que enfrentaram o Rio Grande do Sul, sendo este último o foco da Fire Mok.

## Solução

O Fire Mok será uma plataforma inteligente de monitoramento de enchentes, para análise de cenários e ajudar gestores públicos a identificar áreas vulneráveis, para adaptar.

Seguindo alguns pilares:

- Monitoramento de enchentes
- Análise de precipitacao, umidade do solo, informações territoriais para previsao de regiões que ocorrem grande volume de chuva. Identificar áreas vulneráveis.
